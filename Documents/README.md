# Antimicrobial Drugs as Anticancer Agents

## About This Project

This repository documents my learning journey in R programming, computational biology, and cancer drug repurposing.

My research interest is to explore the potential of antimicrobial drugs as anticancer agents in three cancer types:

- Hepatocellular carcinoma (HCC)
- Pancreatic cancer
- Triple-negative breast cancer (TNBC)

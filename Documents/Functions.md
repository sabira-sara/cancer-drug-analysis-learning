## R Functions and Packages

| **Function/package** | **Purpose** |
|---|---|
| `getwd()` | Check working directory |
| `setwd()` | Set working directory |
| `read_csv()` | Import CSV files |
| `write_csv()` | Export CSV files |
| `head()` | View first rows |
| `names()` | Inspect column names |
| `str()` | Inspect data structure |
| `dim()` | Check dataset dimensions |
| `class()` | Identify object class |
| `select()` | Select columns |
| `filter()` | Filter observations |
| `mutate()` | Create or modify columns |
| `arrange()` | Sort observations |
| `count()` | Count observations |
| `distinct()` | Identify unique records |
| `inner_join()` | Match datasets |
| `is.na()` | Identify missing values |
| `complete.cases()` | Identify complete observations |
| `ggplot()` | Create visualizations |
| `geom_point()` | Create scatterplots |
| `cor.test()` | Perform correlation tests |
